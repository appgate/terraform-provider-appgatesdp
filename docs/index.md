# Appgate SDP Provider

The `appgatesdp` provider manages [Appgate SDP](https://www.appgate.com/) collectives
through the controller Admin API. One provider release supports several SDP releases:

| SDP version | Admin API version | `api_version` |
|---|---|---|
| 7.0 | v25 | `"v25"` |
| 6.7 | v24 | `"v24"` |
| 6.6 | v23 | `"v23"` |
| 6.5 | v22 | `"v22"` |
| 6.4 | v21 | `"v21"` |

Resources and attributes that differ between API versions are listed in the
[supported API versions guide](guides/api-versions). Upgrading from 1.x? See the
[migration guide](guides/migrating-to-v2).

## Example Usage

```terraform
terraform {
  required_providers {
    appgatesdp = {
      source  = "appgate/appgatesdp"
      version = "~> 2.0"
    }
  }
}

provider "appgatesdp" {
  url          = "https://controller.example.com:8443/admin"
  username     = var.username
  password     = var.password
  api_version  = "v25" # SDP 7.0; omit to negotiate with the controller
  pem_filepath = "controller-ca.pem"
}

variable "username" {
  type = string
}

variable "password" {
  type      = string
  sensitive = true
}
```

## API version selection

Set `api_version` to the Admin API version of your controller. If it is unset, the provider
asks the controller which versions it accepts at the first request and uses the newest one
both sides support.

Terraform loads resource schemas before the provider is configured, so every resource
exposes the union of the attributes of all supported API versions. The configured version
decides what is accepted:

* using a resource that does not exist in that version, or setting an attribute it does not
  support, is an error at plan time, before any API call;
* attributes the version requires are enforced at plan time;
* only attributes known to that version are sent to the API.

## Authentication

Credentials are resolved in this order: the file referenced by `config_path`, the provider
block, then environment variables.

* **Username and password** (`username`, `password`, optionally `provider` for a non-local
  identity provider). The token is cached and renewed automatically when it expires. While a
  controller is starting, login is retried on connection errors and HTTP 5xx for up to
  `login_timeout`.
* **Bearer token** (`bearer_token`) obtained outside Terraform, for example from an MFA
  enabled login.

The API user must be exempt from Admin MFA to use username and password.

TLS certificates are always verified unless `insecure = true`. Set `pem_filepath` to the
controller CA when it is not trusted by the system; use `insecure` only for test
environments.

### `config_path` file format

```json
{
  "appgate_url": "https://controller.example.com:8443/admin",
  "appgate_username": "admin",
  "appgate_password": "secret",
  "appgate_provider": "local",
  "appgate_api_version": "v25",
  "appgate_pem_filepath": "/etc/ssl/controller-ca.pem",
  "appgate_login_timeout": "10m"
}
```

## Schema

### Optional

- `api_version` (String) SDP Admin API version, one of v21, v22, v23, v24, v25. When unset, the newest version supported by both the controller and the provider is negotiated at login. Env: APPGATE_API_VERSION.
- `bearer_token` (String, Sensitive) Admin API token obtained outside Terraform; replaces username and password. Env: APPGATE_BEARER_TOKEN.
- `client_version` (Number, Deprecated) Deprecated numeric API version. Env: APPGATE_CLIENT_VERSION.
- `config_path` (String) Path to a JSON file with provider settings (keys appgate_url, appgate_username, ...). Env: APPGATE_CONFIG_PATH.
- `debug` (Boolean, Deprecated) Deprecated. Env: APPGATE_HTTP_DEBUG.
- `device_id` (String) UUID identifying this client in login requests. Defaults to a UUID derived from the machine ID. Env: APPGATE_DEVICE_ID.
- `insecure` (Boolean) Skip TLS certificate verification. Defaults to `false`; prefer `pem_filepath` for controllers with a private CA. Env: APPGATE_INSECURE.
- `login_timeout` (String) How long to retry login while the controller is starting, as a duration (default `10m`). Env: APPGATE_LOGIN_TIMEOUT.
- `password` (String, Sensitive) Admin password. Env: APPGATE_PASSWORD.
- `pem_filepath` (String) Path to the controller CA certificate in PEM format. Env: APPGATE_PEM_FILEPATH.
- `provider` (String) Identity provider used to log in. Defaults to `local`. Env: APPGATE_PROVIDER.
- `url` (String) Controller admin URL, e.g. https://controller.example.com:8443/admin. Env: APPGATE_ADDRESS.
- `username` (String) Admin username. Env: APPGATE_USERNAME.
